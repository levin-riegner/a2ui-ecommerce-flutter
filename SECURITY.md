# Security

Provider keys stay in session memory and outgoing authorized HTTP headers. Never place them in source, assets, public issues, screenshots, logs, fixtures, `--dart-define` values or commits. Local configuration such as `.env.local` is ignored. The default test suite makes no paid provider calls.

For a suspected vulnerability, use the repository's private GitHub vulnerability reporting channel when enabled, or contact a maintainer through an established private channel. Do not include credentials or an exploit containing private data in a public issue. No dedicated security response SLA is currently promised.

When reviewing connectors, preserve destination validation, cancellation, sanitized errors and request limits. Provider/model output is untrusted: validate commands and catalog IDs before changing host state. The bag is a local demo; it provides no checkout, reservation or payment authority.
